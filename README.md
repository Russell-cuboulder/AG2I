# AG2I — Artificial Geospatial General Intelligence

### [ag2i.ai](https://ag2i.ai)

![AG2I — Artificial Geospatial General Intelligence](https://ag2i.ai/og-image.png)

**AG2I** is a ground-up geospatial processing platform that turns raw aerial, oblique, LiDAR, and satellite data into survey-grade, machine-readable products — with accuracy you can **prove**, not just quote. Fully automated, adaptive workflows are designed around the data, not the other way around.

## Case study — independent aerotriangulation of a Vexcel UltraCam Dragon block

Measured against the manufacturer's reference solution on the publicly distributed Graz demonstration block:

| Metric | AG2I (independent) | Reference |
| --- | :---: | :---: |
| Image σ₀ (precision) | **0.64 px** | 0.82 px |
| True vertical accuracy (independent check points) | **0.25 m** | — |
| Camera focal length vs. factory calibration | **0.025 mm** | — |

## The Open Geospatial Suite

| Module | Role |
| --- | --- |
| **OpenStereo** | Dense multi-view stereo photogrammetry (DSM/DTM) |
| **OpenLiDAR** | Full raw-to-product LiDAR processing |
| **OpenGlobe** | WebGL virtual globe for geospatial visualization |
| **OpenLineWorks** | Vector & raster alignment and registration |
| **OpenGeoserve** | Server-side GPU rendering and pixel streaming |
| **OpenNavHD** | HD mapping & positioning for autonomous vehicles |
| **OpenVoxelite** | Volumetric fusion of imagery and LiDAR |
| **OpenGeoLook** | Geospatial data discovery and conditioning |
